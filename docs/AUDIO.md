# Audio Assets

This document details the soundtrack assets created for and bundled with Abyss Delver 3D.
All music tracks are generated procedurally and bundled locally under `public/audio/`.

---

## Generation & Verification

To reproduce or re-generate these audio files:

```bash
python3 scripts/gen-music.py
```

The script uses only the Python 3 standard library (`math`, `wave`, `struct`, `tempfile`, `subprocess`) to synthesize sample-accurate loop waveforms, then encodes them using `ffmpeg` to 64 kbps mono MP3 files under `public/audio/`.
